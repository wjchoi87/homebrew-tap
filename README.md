# homebrew-tap

Homebrew tap for [Pawmit](https://github.com/wjchoi87/Pawmit) — a macOS desktop pet that answers AI coding agents' approval prompts, questions, and task notifications.

## Install

```sh
brew install --cask wjchoi87/tap/pawmit
```

Or add the tap first:

```sh
brew tap wjchoi87/tap
brew install --cask pawmit
```
